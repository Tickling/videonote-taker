VideoNote Taker — конспекты видео с таймкодами
==============================================

УСТАНОВКА (один раз, ~5 минут)

1. Установите Node.js (LTS) с https://nodejs.org — обычная установка «Далее → Далее».

2. Запустите сервер:
   • Windows: двойной клик по start-backend.bat
   • macOS:   двойной клик по start-backend.command
              (если macOS не даёт открыть: правый клик → «Открыть»)
   При первом запуске программа сама установит yt-dlp и ffmpeg.
   Окно сервера должно оставаться открытым, пока вы пользуетесь расширением.

3. Установите расширение в Chrome:
   • откройте адрес chrome://extensions
   • справа вверху включите «Режим разработчика»
   • нажмите «Загрузить распакованное расширение» и выберите папку extension
   • закрепите иконку (значок пазла 🧩 → булавка рядом с VideoNote Taker)

4. Добавьте бесплатный ключ Groq — откроется окно настроек; инструкция
   лежит в extension/guides/groq-guide.pdf (кнопка «📖 Как получить ключ Groq?»).

ИСПОЛЬЗОВАНИЕ

• На странице видео YouTube / Rutube / VK Видео нажмите оранжевую кнопку
  справа внизу → «Создать конспект».
• Или нажмите иконку расширения и вставьте ссылку на видео.
• Ctrl+Shift+S — скриншот кадра с таймкодом.
• Готовый конспект можно скачать в Word или Markdown.

ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ

• «Сервер не отвечает» — запустите start-backend и не закрывайте окно.
• YouTube перестал отдавать видео — обновите yt-dlp:
  Windows: winget upgrade yt-dlp.yt-dlp    macOS: brew upgrade yt-dlp
• «Нет автосубтитров» — у видео нет субтитров; включите Whisper в настройках
  (нужен ключ OpenAI, см. openai-guide.pdf) или локальный Whisper.
