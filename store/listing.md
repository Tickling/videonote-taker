# Тексты для Chrome Web Store

Скопируйте в панель разработчика (https://chrome.google.com/webstore/devconsole) → ваш элемент → **Store listing**.

## Название
VideoNote Taker — конспекты видео с таймкодами

## Краткое описание (до 132 символов — это поле берётся из манифеста)
Автоматическая транскрибация видео и конспекты с таймкодами. Бесплатно по умолчанию, мощно по желанию.

## Категория
Productivity (Продуктивность) → Education можно указать во второй категории, если доступна

## Язык
Русский

## Подробное описание
Превращайте видео в аккуратные конспекты за минуту.

VideoNote Taker берёт субтитры видео и с помощью ИИ составляет структурированный конспект с кликабельными таймкодами — прямо рядом с видео.

🎓 Обучающие видео — главные мысли и идеи, о чём урок, таймкоды и помощь от ИИ: что почитать по теме и практический пример.
🎙️ Интервью — основные идеи собеседников, яркие цитаты, выводы и таймкоды.
🎬 Развлечения — краткая суть и таймкоды.
🎞️ Фильмы — мысли и идеи, о чём фильм, герои, таймкоды и оценка ИИ.

Возможности:
• Конспект на странице видео: оранжевая кнопка → «Создать конспект»
• Конспект по ссылке из окна расширения
• Клик по таймкоду перематывает видео
• Скриншоты кадров (Ctrl+Shift+S) с привязкой ко времени и комментариями
• Экспорт в Word и Markdown
• История конспектов с поиском и фильтрами
• YouTube, Rutube и VK Видео

Бесплатно:
Для конспектов нужен только бесплатный ключ Groq (2 минуты, карта не нужна) — пошаговая инструкция встроена в расширение.

По желанию:
• OpenAI Whisper — распознавание речи для видео без субтитров и запись в реальном времени
• OpenAI GPT-4o — ещё более качественные конспекты

Приватность:
Конспекты, ключи и настройки хранятся только в вашем браузере. Мы не собираем историю просмотров и не показываем рекламу.
